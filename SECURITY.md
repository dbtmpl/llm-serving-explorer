# Security

LLM Serving Explorer is a static site: it has no backend, stores nothing about visitors and runs only in the browser.

To report a vulnerability, for example in the site's code or a dependency it ships, use [GitHub's private vulnerability reporting](https://github.com/dbtmpl/llm-serving-explorer/security/advisories/new). Please do not open a public issue for it. You will get an answer within a week.

Only the latest version on `main`, which is what the live site runs, is supported.
